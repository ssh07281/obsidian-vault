## Polymer
같은 구조의 단위, monomer가 반복적으로 결합되어 형성된 거대 분자 : 분자량 10000이상
저분자량 고분자 : 10000~20000
고분자량 고분자 : 20000이상

## Monomer
가장 작은 분자 단위
Monomer is any substance that can be converted into a polymer.

Ex) ethylene -> polyethylene
에틸렌이 쭉쭉 이어지면서 polyethylene 형성
이름을 monomer이름 앞에 poly만 붙이면 됨.

근데 모든 polymer의 이름이 monomer + poly는 아니다. 
특정 유형의 결합이 만들어지면서 고분자가 형성되는 경우 poly+ 결합 유형으로 이름을 지음

==Ex) amino acid -> polypeptide=polyamide==
아미노산에서 물이 빠지면서 고분자를 형성한다.
H-N-CO 결합이 이루어 지면서 고분자를 형성한다.
[[고분자 메커니즘]]

+ 축합 반응
  축합 반응에서 빠지는 물질은 물이 아니어도 됨.
  물이 빠지는 걸 탈수축합 반응

- 펩타이드 결합
  카복실기(COOH)와 아민기(NH2)가 탈수축합 반응을 통해 생기는 결합
  
-> 펩타이드 결합은 탈수축합 반응을 통해 형성되는 결합이고, 아미노산 사이에만 일어나는 결합을 말하는 거구나!
그래서 생성된 고분자의 이름이 polypeptide이구나.
근데 polyamide라고도 불리는데 이 이유는?
-> 이게 아미노산끼리 말고, NH2기를 가진 한 분자와 COOH를 가진 한 분자가 만날 수 있기 때문에, 이때 탈수축합 반응을 통해서 형성된 결합을 아마이드 결합이라고 한다.

아하 아마이드 결합이 더 큰 개념이고, 그 중 아미노산끼리의 결합을 특별하게 펩타이드 결합이라고 하는구나. 

> [!NOTE] 헷갈렸던 부분
> : polypeptide를 polyamide로 부를 수 있는 이유?
> 다른 분자가 아마이드 결합하여 고분자를 만들 수 있긴 하나, 오직 아마이드 결합만 가지는 고분자는 아미노산끼리 결합한 polypeptide이므로 polyamide라고 부를 수 있다.


==Ex) diol + dicarboxylic acid==
-OH기 2 개를 가지고 있는 diol
COOH기 2개를 가지고 있는 dicarboxylic acid
얘들끼리(두 가지 이상의 반응물이) 탈수축합 반응 하면 물이 빠지고 새로운 반응이 일어나면서 사이즈가 큰 고분자가 생성된다.
근데 여기서는 탈수축합 반응이 일어나 에스터 결합을 한다.
따라서 생성된 고분자의 이름은 polyester이다.


## 비닐계 화합물

비닐계 monomer란 ? 
nCH2=CHX를 비닐계 monomer라고 함.
넓은 의미에서는 nCH2=CX2 를 비닐계 monomer라고 하기도 함.
-> 알케인 화합물 형태 (메탄, 에탄, 프로판, 부탄, 펜탄 ...)

#### 비닐계 화합물 예시
순서는 비닐계 monomer -> 비닐계 화합물

- ethylene -> polyethylene (PE)

- styrene -> polystyrene (PS)

- 염화비닐 -> 폴리염화비닐 (PVC)

- propylene(propane) -> polypropylene

- 메틸메타크릴레이트 (MMA) -> 폴리메틸메타크릴레이트 (PMMA)
  메틸아크릴레이트는 CH2CHCOOCH3인데, 메틸메타크릴레이트는 가운데 H가 CH3가 됨.
  특징으로는 99.9%의 빛을 투과한다. 헤드라이트나 렌즈에 사용된다.

- 테트라플루오로에틸렌 -> 폴리테트라플루오로에틸렌

-> 비닐계 고분자는 물질 앞에 poly를 붙이면 고분자 이름이 되는구나!


## Oligomer
올리고머 : 분자량 10000미만의 중합체 물질 (monomer와 polymer 사이의 물질)

단량체 : monomer
이량체 : dimer
삼량체 : trimer
사량체 : tetramer
오량체 : pentamer
육량체 : hexamer
칠량체 : heptamer
팔량체 : octamer
...
고분자 : polymer

그럼 이 분자가 monomer인지 oligomer인지 polymer인지 알 수 있을까?
-> 분자량 10000이상이 polymer니까, 가장 작은 polymer에 몇 개의 monomer가 들어있을까를 계산
: ex) polyethylene : 분자량 28g/mol, (10000g/mol) / (28g/mol) = 357.14 
357개보다 적으면 oligomer, 358개부터 polymer이다. (특히 low polymer)
